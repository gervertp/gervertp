## 📌 Proyecto destacado

### [Sistema de Gestión de Biblioteca](https://github.com/gervertp/biblioteca)

Aplicación web Full Stack para administrar **libros, autores, socios y préstamos** mediante una API REST y un frontend SPA.

- Backend con **Laravel 13** y autenticación mediante **Laravel Sanctum**.
- Frontend con **Vue 3, Pinia, Vue Router y Tailwind CSS**.
- CRUD completo de libros, autores, socios y préstamos.
- Búsqueda en tiempo real y paginación.
- Entorno de desarrollo con **Docker + Laravel Sail**.
- Pruebas automatizadas con **PHPUnit**.
