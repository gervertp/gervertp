## 📌 Proyecto destacado

### [Sistema de Gestión de Biblioteca](https://github.com/gervertp/biblioteca)
Sistema web completo con API REST y frontend SPA.
- API REST con Laravel 13 y autenticación por tokens (Sanctum)
- Frontend en Vue 3 con Pinia, Vue Router y Tailwind CSS
- CRUD de libros, autores, socios y préstamos
- Búsqueda en tiempo real y paginación
- Tests automatizados con PHPUnit
- Base de datos con 2000 libros, 500 autores y 500 socios de prueba
