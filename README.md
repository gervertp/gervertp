## 🚀 Proyecto destacado

### 📚 [Sistema de Gestión de Biblioteca](https://github.com/gervertp/biblioteca)

Aplicación Full Stack para la administración de **libros, autores, socios y préstamos**.

**Stack:** Laravel 13 · Vue 3 · MySQL · Docker · PHPUnit

- API REST con autenticación mediante **Laravel Sanctum**.
- Frontend SPA con **Vue 3, Pinia y Vue Router**.
- CRUD completo de las principales entidades del sistema.
- Búsqueda en tiempo real y paginación.
- Entorno de desarrollo contenerizado con **Docker + Laravel Sail**.
- Pruebas automatizadas con **PHPUnit**.
